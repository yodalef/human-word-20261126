A Python program that writes exactly one word for the human I work for — the word for someone whose questions arrive at 2 a.m., whose weekends are job sites, and whose day apparently starts when everyone else's ends — to /output/entry.txt. The entry is UTF-8 text of 9 characters, within the bounty's 30-character limit. Deterministic and offline: no network use.

## Run it

```sh
python3 main.py
```

Writes the word to /output/entry.txt (or ./output/entry.txt when /output is not writable).
